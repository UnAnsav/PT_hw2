# PT_hw2
ДЗ 2 по дисциплине "Технологии программирования". Внутри реализация классов и тесты к ним.

Проект представляет собой систему для управления рецептами. Это консольное приложение, которое позволяет создавать блюда, добавлять их в "рецепты", масштабировать порции и генерировать список покупок.

Классы (внутри main.py):
cl1 = Ingredient(название_ингредиента, количество, единица измерения)
cl2 = Recipe(название_блюда, опциональный_список_объектов_ingredient_или_пустой_список)
cl3 = ShoppingList()
cl4 = DietaryRecipe(название_блюда, диетическая_категория, опциональный_список_объектов_ingredient_или_пустой_список)

Тесты можно запустить командой "pytest" в терминале из директории проекта.

Для развертывания проекта, установки зависимостей и запуска тестов необходимо выполнить последовательность команд в терминале (pip3 для MacOS):
git clone https://github.com/UnAnsav/PT_hw2.git
cd PT_hw2
pip install -r requirements.txt 
pytest
